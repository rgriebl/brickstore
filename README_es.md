1. **Solo output en español**: No se debe incluir ningún resultado envuelto en marcos de código.
2. **Mantenimiento estructural**: Se debe conservar íntegramente la estructura original de Markdown, los sangrados, los niveles de título, las tablas, los enlaces, las URL, las insignias, los bloques de código y el código inline.

4. **Prohibición de modificaciones**: Está **estrictamente prohibido** traducir o modificar etiquetas de código, nombres de claves, placeholders de variables (como {{var}}, ${var}, %s, %d, etc.), ejemplos de comandos, rutas de archivos, nombres de proyectos, nombres de API, nombres de paquetes, nombres de modelos, identificadores y símbolos de código; a menos que el texto original ya incluya su traducción correspondiente.

## BrickStore

BrickStore es una herramienta de gestión sin conexión para BrickLink. Es **multiplataforma** (Windows, macOS y Linux, además de iOS y Android), **multilingüe** (actualmente inglés, alemán, español, sueco y francés), **rápida** y **estable**.
